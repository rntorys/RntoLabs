# RntoLabs

Portafolio personal de Renato Reyes: proyectos, productos digitales y experimentos desarrollados mientras estudio Ingeniería Civil Informática en la Universidad Técnica Federico Santa María.

## Contenido

- Presentación personal.
- Proyectos: Lectum, Aurum, Weblio, Mintora y RntoLabs.
- Filtros por categoría.
- Tema claro y oscuro.
- Diseño adaptable para computador y celular.

## Publicación con GitHub Pages

El sitio no necesita instalación ni proceso de compilación. Se publica directamente desde la rama `main` y la carpeta raíz del repositorio.

Desarrollado con HTML, CSS y JavaScript.
